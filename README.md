# REST API для управления кошельками

## Описание

Реализация REST API для управления кошельками, позволяет выполнять операции пополнения и снятия, а также проверки баланса. 


## Функциональность

Предоставляет методы:

`POST /api/v1/wallet`

Пополнение `DEPOSIT` или снятие `WITHDRAW` средств.


*Тело запроса:*
```json
{
  "valletId": "UUID", // ID кошелька 
  "operationType": "DEPOSIT" // Или "WITHDRAW",
  "amount": 1000 // Сумма, может быть дробной (123.45)
}
```

`GET /api/v1/wallets/{WALLET_UUID}`

Получение баланса кошелька.

**Ответ:**
```json
{
  "walletId": "UUID",
  "balance": "1234.56" // Баланс строкой, для точности
}
```

Выполнить:
`make build`
`make up`

Запуск тестов `make test`.


### Покрытие тестов

#### Позитивные сценарии

*Пополнение счета*- операция DEPOSIT на существующий кошелек.
*Снятие средств*- операция WITHDRAW при достаточном балансе.
*Получение баланса*- GET запросы для проверки баланса.
*Работа с дробными суммами*- операции с копейками.
*Последовательные операции*- цепочка DEPOSIT/WITHDRAW с проверкой баланса.

#### Обработка ошибок

*Недостаточно средств*- операция WITHDRAW c достижением отрицательного баланса.
*Кошелек не найден*- операции с несуществующим UUID.
*Невалидный UUID*- некорректный формат UUID.
*Пустой UUID*- отсутствие UUID кошелька.
*Несуществующая операция*- неизвестный тип операции.
*Отрицательная сумма*- DEPOSIT/WITHDRAW с amount < 0.
*Некорректная точность*- amount больше 2 знаков после запятой.
*Невалидный JSON*- синтаксические ошибки в теле запроса.

#### Нагрузочное тестирование

*1000 одновременных `DEPOSIT`*- массовое пополнение (100 потоков).
*1000 одновременных `WITHDRAW`*- массовое снятие (100 потоков).
*Проверка целостности*- корректность итогового баланса после нагрузки, отсутвие (50Х error).


## Допущения 
*Тип данных баланса*
Баланс возвращается строкой, а не числом, для точного представления чисел с использованием типа `DECIMAL`.

*Название поля*
В ТЗ в запросе на изменение баланса поле называется `valletId` вместо `walletId`. Согласно ТЗ это имя оставил без изменений.

*Путь к балансу*
 В ТЗ указан путь `GET api/v1/wallets/{WALLET_UUID}`. Использовано множественное число `wallets`. Согласно ТЗ это имя оставил без изменений.
